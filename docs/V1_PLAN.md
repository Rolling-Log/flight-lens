# V1 执行计划

1. 正式基线：单仓多应用、文档、ADR、Git 和 CI；
2. 领域核心：SearchIntent、Offer、Connector、全价、去重、排序、Neon Schema；
3. API：并行编排、来源状态、审计、限流、超时和降级；
4. 双输入前端：条件同步、进度、结果、覆盖、价格与来源；
5. 实时购买交接来源：SerpApi Google Flights 与同程实时页面已完成同次本地查询；飞猪 FlyAI、携程、去哪儿已实现但分别受正式 Key、风控页和页面结构限制；
6. Staging：Netlify Web、Railway API、Neon、回归和验收报告。

本地 V1 门槛已达到同次查询两个实时来源成功。上线发布仍需复核各来源的长期展示许可、落地页价格和运行稳定性；只有 Connector 代码、错误页、Sandbox 响应或单次偶发成功不算稳定运营完成。

稳定运营目标采用 2+2 结构：在两个购买交接来源之外，再配置两个 production 核验来源。核验来源可以发现反例，但没有消费者购买落点时不得进入最低价推荐。
