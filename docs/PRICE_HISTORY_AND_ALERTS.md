# 价格历史、五档判断与提醒

## 数据层次

1. 外部市场历史：SerpApi 在当前 Google Flights 查询中返回的 `price_insights.price_history`。它可以让首次查询直接出现历史，但仍属于来源展示价。
2. 本站查询留存：用户或后台任务真实运行航探时写入 Neon 的观测。它按最低可核验全价、来源展示价、分开购买价分别保存，不与外部历史拼接。

界面必须分别标出数据来源、30/90/180 天统计范围、更新时间、观测日数量和可信度。没有数据的日期保留为空白，曲线不得跨缺口补线。

## 五档价格判断

横轴固定从偏贵到更划算：

| 等级 | 含义 | 默认边界 |
|---|---|---|
| 拉完了 | 明显偏贵 | 高于 P80 |
| NPC | 偏贵 | P60 到 P80 |
| 人上人 | 正常区间 | P40 到 P60 |
| 顶级 | 比多数历史价格划算 | P20 到 P40 |
| 夯 | 历史低位 | 不高于 P20 |

等于分位边界时进入更有利的一档。横轴标出当前价格、P20-P80 典型区间和 P50 历史中位数。外部历史至少需要 5 个不同观测日；30 个及以上观测日为高可信度，否则为中可信度。只有典型区间没有逐日历史时可以作低可信度判断。

以下情况不判断：航线、日期、行程类型、舱位、成人数、币种或价格口径不一致；当前价是两张单程分开购买价；没有足够历史；价格字段异常。

## 提醒如何送达

价格提醒由服务端定时运行，网页可以关闭。免费部署采用 GitHub Actions 每小时唤醒 API，API 通过 pg-boss 和 Neon 领取到期任务，达到目标价后向用户提供的 ntfy topic 推送。

提醒时间不是实时 SLA：Render 免费实例可能冷启动，GitHub Actions 和上游来源也可能延迟。前端应展示提醒状态、最近检查、下次计划、最后错误和重试入口。没有配置服务端调度时，API 返回 `MONITOR_UNCONFIGURED`，前端禁止创建并明确说明不会发送通知。

## 来源限制

SerpApi 是否返回 `price_insights` 取决于具体市场、航线、日期和 Google Flights 响应；不能保证每次都有。它的历史展示价不能替代 OTA 支付页的税费、机建燃油、行李和退改核验。Edge Companion 仍只负责借助用户的浏览器会话读取来源证据，不负责生成市场历史或后台提醒。
