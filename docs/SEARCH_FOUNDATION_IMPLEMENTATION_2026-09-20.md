# 搜索底层重构：第一批实现

对应设计：[搜索底层重构评估](SEARCH_FOUNDATION_REVIEW_2026-09-20.md)。

## 已实现

- 浏览器会话来源不读取、不写入公共执行缓存；新观察和新的登录失败都不被旧结果覆盖。
- 同平台公共接口和本机浏览器作为独立执行入口保留；失败、空结果和不支持条件均保留报告。
- 报价去重增加渠道、商品、价格证据、行李与资格条件，避免把不同商品合并后丢掉候选。
- 网页立即并行启动云端查询与扩展查询，各浏览器平台结束后独立更新结果。
- 增加 `/v1/searches/companion`：只规范化已采集的浏览器结果，不调用公共供应商、不写公共价格历史，响应禁止共享缓存。
- 来源弹窗可单独重试平台；扩展在同一航探标签页、同一条件下恢复登录等待任务，保留已完成的往返航段。
- 新回复按执行入口替换旧尝试，保留其他入口报价；迟到结果不能合入新搜索，也不清空用户正在看的详情。
- 去掉服务端 30 条卡片截断，提高扩展传输上限到 500 条；去哪儿按可见下一页控件进行有界翻页。
- 披露已读页数、范围未知或部分完成；继续使用宽城市查询时，在完整采集范围内再匹配用户指定机场。
- 扩展版本升级为 0.2.0，网页兼容旧版整批回复，旧版的单平台重试明确要求重载。

## 验证

- `pnpm check` 通过：类型检查、lint、175 项单元/集成测试、生产构建。
- 桌面及手机 24 项 E2E 通过。新增测试将扩展故意保持为未完成，证明云端报价先出现；登录重试只发送 `platforms: ["ctrip"]`，公共搜索请求总数仍为 1。
- 离线分页样本：11 个同样大小的页面读到 220 个不同候选；翻页停滞保留已有候选并标为 partial。
- 新观察 399 元取代旧观察 520 元的回归测试通过；这些金额是合成测试数据。
- 修改过的扩展任务流程单独复跑 3 项测试通过，覆盖登录恢复和分页。

## 本批次的边界

尚未证明真实国内最低可购买价命中率提高。当前改动解决已确认的丢失与编排问题，供应内容增量需要真实查询对照。

真实 Edge 控制通道本轮出现 CDP 超时，重新打开去哪儿时返回 `net::ERR_BLOCKED_BY_CLIENT`，因此没有把离线分页测试宣称为线上验收。
用户本地扩展需要在 `edge://extensions` 重载到 0.2.0，网页发布后也需要刷新，才能使用增量回复和单来源恢复。

仍待推进：

1. 真实去哪儿页面翻页验收与上游机场筛选；其他平台的列表滚动、分页与卖家产品展开。
2. 云端公共接口之间更细粒度的增量返回；当前公共接口仍由服务端并发查询后整批返回，已与浏览器解耦。
3. 跨网页刷新/浏览器重启的持久化任务及取消机制；本批次页面内结果不持久化，扩展登录恢复保留 30 分钟。
4. FlyAI 定向航班/日期分区实验、新供应接口的权限及购买交接确认。
5. 20 航线 × 3 日期的真实价格对照、完整产品与费用复核。

首批改动不新增商业供应商、不触发出票或支付，也未承诺全网最低价。
